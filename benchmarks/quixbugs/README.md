# QuixBugs tasks

Generated by `python benchmarks/import_quixbugs.py --source <QuixBugs checkout>` from
https://github.com/jkoppel/QuixBugs (commit `4257f44b0ff1181dedaedee6a447e133219fcebf`). The programs, tests and
test data are QuixBugs' own (MIT license, see LICENSE); each task holds the buggy program,
its pytest file and its JSON test cases. The correct versions were used only to check that
each task's tests fail before and pass after the fix, and are not included.

`metadata.defect_class` is derived from the diff between the buggy and the correct function
(`classify_defect` in the importer). The split alternates each class between train and
held-out, so every held-out task has a train task with the same defect class.
